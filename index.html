它能做什么

不是只会聊天，它真的动手

你说话，它干活。说人话就行，不用学什么提示词。

下载完，双击就能用

不需要装开发环境，不需要敲命令。下载一个文件，双击打开，填一次你的 API 钥匙，之后就正常用。

它真的会帮你动手

不是给你一堆建议让你自己弄。整理文件夹、读文档、改代码 —— 你交代的事它直接做完，再告诉你结果。

一只小泰迪陪着你

它叫摩尼。你让它干活它会翻书用功，出错它会哭给你看，你不理它它就趴下睡觉。桌面上的活宠物。

东西都在你自己电脑上

聊天记录和文件都留在本地，不会偷偷传给别人。用本地模型的话，断网也能用。

免费，是真免费

代码全公开，没有会员，没有功能墙。你只需要付给模型提供方该付的钱；用本地模型就一分不花。

想换谁家的「脑子」都行

今天用这家，明天换那家，界面完全不变。填个地址和钥匙就切过去了，不重装。

特性

该有的都有，不该重的一点不重

不是又一个 Electron 套壳。MollyPaw 把重量留给了 Python 的简单。

超轻量

没有 Rust，没有 Node.js，没有 npm。一个 pip install，一个 python main.py，完事。

Windows 原生

就是给 Windows 做的。系统托盘、宠物子进程、WebView2 都按 Windows 写的，不假装跨平台。

启动快、体积小

不背 Chromium 的包袱。冷启动就是开一个本机窗口，界面渲染走系统 WebView。

接你自己的模型

OpenAI / Claude / 本地模型 —— 只要是 OpenAI 兼容接口，填个 API Key 和 base_url 就能用。

桌面宠物

摩尼是独立进程的小泰迪，每秒同步 Agent 状态：待命、干活、崩溃、摸鱼睡觉。

工具可以自己长

定义一个 Python 类，写上 TOOLS 和 execute，注册进 ToolRegistry —— Agent 立刻多一只手。

🔑 API 钥匙是什么？

AI 不是免费的公共设施，它由各家厂商提供。你要先去厂商网站注册一个账号，拿到一串「钥匙」，填进 MollyPaw，它才能替你问 AI。

常见去处：DeepSeek、Kimi、通义、OpenAI、Anthropic。价格按用量算，聊天级别一个月通常几块钱。

不想花钱？ 用本地的开源模型，全程离线、零费用，但要你自己装一次模型。装好之后在设置里把地址填成本机地址就行。
快速开始

从零到跑起来，两分钟

唯一的前置条件：装好 Python 3.9 或更高版本。

  1. 1

    拿代码

    克隆仓库，或者直接下 Release 里的 MollyPaw.exe。

  2. 2

终端 
# 1. 克隆仓库
git clone https://github.com/LK-BLOG/MollyPaw.git
cd MollyPaw

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动
python main.py

# 调试模式（打开 webview devtools）
python main.py --debug

下载之后怎么弄？

  1. Windows 可能会弹「已保护你的电脑」。点「更多信息」→「仍要运行」。这是没买签名证书的正常现象，不是病毒。
  2. 文件放桌面就行，不需要安装。以后想删掉直接删文件。
  3. 第一次打开会让你填 API 钥匙。没钥匙先去模型官网注册一个，复制过来粘上。
  4. 填完就能聊了。旁边那只狗是摩尼，点它可以跟它玩。
找不到 API 钥匙？ 小白推荐先试 DeepSeek：官网注册 → 充值几块钱 → 在「API Keys」页面新建一个 → 复制以 sk- 开头的那串。然后打开 MollyPaw 设置，供应商选 DeepSeek，把钥匙粘进去即可。

FAQ

你可能想问的

我完全不会写代码，能用吗？

能。你是使用者，不是开发者。下载 exe、双击、粘一次 API Key，剩下的就是打字聊天。

要我注册账号吗？

MollyPaw 自己不需要账号。但你得有一个 AI 模型提供方的账号，因为 AI 是那边在算钱。

要花多少钱？

程序本身永久免费。模型按用量计费，普通聊天一个月几块钱；用本地模型就是零成本。

我的文件安全吗？

程序在你电脑上跑，文件也在本地。只有你主动让它做的事，内容才会发给你配置的那家模型。

它到底能帮我做什么？

整理下载文件夹、把一堆文档读成摘要、翻译、改代码、批量重命名、写脚本 —— 你描述目标，它动手。

它记不记得住我说过的话？

记得。你在一个对话里的上下文它保持；你告诉过它的长期偏好和要求，它也会记下来，换个对话照样认。它还会在空闲时自己「睡一觉」，把重要的事整理进长期记忆，不重要的丢掉。

GitHub 打不开，下载不动怎么办？

正常，国内直连 GitHub 就是会抽。用上面的国内加速镜像，随便挑一个，下下来的文件跟官方一模一样。

Windows 说「已保护你的电脑」？

因为我们没买代码签名证书（那玩意儿挺贵）。点「更多信息」→「仍要运行」就行。不放心可以不装。

那只狗能关掉吗？

能。宠物是独立的小窗口，关掉完全不影响聊天。

装了打不开怎么办？

先确认系统是 Windows 10/11。还是不行的话去 GitHub 提个 Issue，把报错截图贴上去。

FAQ

你可能想问的

要花钱吗？

MollyPaw 本身免费，GPLv3 开源。你只需要自己付模型 API 的钱，用本地模型就是零成本。

支持哪些模型？

任何 OpenAI 兼容接口，包括 OpenAI、Claude（兼容网关）、以及本地部署的模型。设置面板里填 API Key、base_url、模型名即可。

必须联网吗？

程序本地运行，数据只发给你在设置里填的那个 API 地址。用本地模型就完全离线。

那只狗能关掉吗？

能。宠物是独立进程，关掉不影响主程序聊天。

我能给它加工具吗？

可以。定义一个 Python 类，提供 TOOLS 和 execute()，注册进 ToolRegistry 就完事。

为什么不用 Electron？

因为目标用户不需要为了一个聊天窗口装一百多兆的运行时。能 pip 解决的事，不引入构建链。

站点的版本号哪来的？

前端直接请求 api.github.com/repos/LK-BLOG/MollyPaw/releases（带 CORS，每 IP 每小时 60 次），版本号、发布时间、资产大小、历史记录全部实时取。请求失败时回落到同目录的静态快照 releases.json。

国内拉不到 Release 怎么办？

页面里的镜像列表会并行探一次 HEAD 到各加速节点的真实资产地址，把通的排前面。加速节点列表在 assets/js/main.js 里，挂了自己加。
