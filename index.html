聊天记录存在你本机，不会传给别人。只有你主动让它做的事，才会发给你填的那家 AI 公司。

程序免费，用多少付多少

软件本身不收费，永久免费，不是试用版。日常聊天一个月几块钱，相当于一杯奶茶。

特性

不是又一个 Electron 套壳。MollyPaw 把重量留给了 Python 的简单。

没有 Rust，没有 Node.js，没有 npm。一个 pip install，一个 python main.py，完事。

怎么用

三步，十分钟以内

会用微信，就会用这个。

  1. 1

    下载

    点上面的橙色按钮，会下一个叫 MollyPaw.exe 的文件。放到桌面就行，不用安装。

  2. 2

    第一次打开会弹一个警告

    Windows 会说「已保护你的电脑」—— 点「更多信息」，再点「仍要运行」。这是因为我们没买微软的签名证书，不是病毒。

  3. 3

    填一串密码（只有这一步有点麻烦）

    MollyPaw 自己不带 AI，它要连一家 AI 公司。注册、拿到钥匙、粘进去，三步。下面详细写。

  4. 4

    开始打字

    在输入框说你要干什么，像发微信一样。比如「把桌面上的截图按日期分好类」。

🔑 那串「钥匙」是什么，怎么弄到手

把 MollyPaw 想成一台没有大脑的机器人：它会动手，但不会思考。 「大脑」是别人家的，就像你手机里的豆包、Kimi 那样。

钥匙就是你去那家领的通行证，长得像一串乱码：sk-a1b2c3d4...。 填进 MollyPaw，它才能替你问那边。

下面照着点就行（用 DeepSeek，最便宜）。 全程在电脑上操作，大概 5 分钟。

  1. 你现在正在看这个页面。 你用来打开它的那个东西，就叫「浏览器」—— 别关掉它，就用它。
  2. 抬头看它最上面，有一条又长又能打字的横条 （现在里面写着 mollypaw.pages.dev）。
    mollypaw.pages.dev
    你正在看的内容
    ↑ 就点这条长横条
  3. 点一下那条横条，把里面原有的字全部删掉， 输入这串：
    platform.deepseek.com
  4. 键盘上找一个上面印着 ↵ 弯箭头的键 （通常在键盘右边，靠下；有些键盘上直接写着 Enter 或「回车」）。 按它一下，浏览器就会带你过去。
    ↵ Enter 认这个弯箭头，别认大小

    按错了（比如按到 Shift、Ctrl）不会有任何事发生， 也不用怕 —— 再按一下那个 ↵ 就行。实在乱了就把横条里的字重新删掉再输一次。

  5. 等一下，会跳到一个新页面。 上面会让你登录：填你的手机号，点「发送验证码」， 然后看手机短信，把那 6 个数字填进去，点登录。
  6. 第一次用会让你做实名认证（填姓名和身份证号）。 这是国家要求的，所有 AI 平台都要，不是我们骗你。
  7. 登录进去后，左边一排菜单里点「充值」， 充 10 块钱（够你聊很久了），用微信或支付宝都行。
  8. 再点左边的「API keys」，点右上角黑色的「创建 API key」按钮。
  9. 屏幕中间会弹出一串 sk- 开头的东西 —— 这就是钥匙。点旁边的「复制」，立刻粘到 MollyPaw 设置里。
⚠️ 两个坑，踩了就白干：
  • 那串钥匙只显示这一次。关掉弹窗就再也看不到了，只能删了重新建一个。
  • 别把钥匙发给任何人。谁拿到都能花你的钱，发群聊截图前记得打码。

从零到跑起来，两分钟

唯一的前置条件：装好 Python 3.9 或更高版本。

  1. 1

    拿代码

    克隆仓库，或者直接下 Release 里的 MollyPaw.exe。

  2. 2

    装依赖

    只要一条命令。pywebview、requests、pillow 这些就位。

终端 
# 1. 克隆仓库
git clone https://github.com/LK-BLOG/MollyPaw.git
cd MollyPaw

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动
python main.py

# 调试模式（打开 webview devtools）
python main.py --debug
Windows 10 / 11 打包 exe：.\build.bat → dist\MollyPaw.exe

下载之后怎么弄？

  1. 下载好之后，桌面上会多一个 MollyPaw 图标。双击它，软件就开了。
  2. Windows 可能弹「已保护你的电脑」。点「更多信息」→「仍要运行」。这是因为没买微软的签名证书，不是病毒。

FAQ

你可能想问的

我完全不会写代码，能用吗？

能。这东西就是给不会写代码的人用的。你要做的只有三件事：下载、双击、粘一次钥匙。剩下全是打字聊天。

要我注册账号吗？

MollyPaw 自己不用注册。但「钥匙」得去 AI 那边领，所以那边要注册一个，用手机号就行。

要花多少钱？

软件不要钱，一直免费，不是试用。给 AI 那边的钱按用量算，普通聊天一个月几块钱，大概一杯奶茶。

我的文件安全吗？

软件在你电脑上跑，文件也在你电脑上。只有你主动让它做的事，内容才会发给你选的那家 AI。

它到底能帮我做什么？

把乱糟糟的下载文件夹归类、把一堆 PDF 读完给你总结、翻译、批量改文件名、整理照片。你描述清楚要什么，它动手。

它记不记得住我说过的话？

记得。同一段聊天里的事它一直记着；你告诉过它的长期习惯，换个对话它也认。它还会在闲着的时候自己「睡一觉」，把重要的事记下来，不重要的丢掉。

下载不动 / 点下载没反应怎么办？

多试几次，或者用下面「换条线路」里别的线路。哪个能下就用哪个，文件完全一样。

Windows 说「已保护你的电脑」？

因为我们没买微软那个签名证书（挺贵的）。点「更多信息」→「仍要运行」就行。实在不放心就别装。

那只小狗能关掉吗？

能。它是个小窗口，关掉完全不影响聊天。

装了打不开怎么办？

先确认你的电脑是 Windows 10 或 11。还不行的话，把报错的画面截图，发到下面那个反馈的地方，我们看看。

FAQ

你可能想问的

要花钱吗？

MollyPaw 本身免费，GPLv3 开源。你只需要自己付模型 API 的钱，用本地模型就是零成本。

支持哪些模型？

任何 OpenAI 兼容接口，包括 OpenAI、Claude（兼容网关）、以及本地部署的模型。设置面板里填 API Key、base_url、模型名即可。

必须联网吗？

程序本地运行，数据只发给你在设置里填的那个 API 地址。用本地模型就完全离线。

那只狗能关掉吗？

能。宠物是独立进程，关掉不影响主程序聊天。

我能给它加工具吗？

可以。定义一个 Python 类，提供 TOOLS 和 execute()，注册进 ToolRegistry 就完事。

为什么不用 Electron？

因为目标用户不需要为了一个聊天窗口装一百多兆的运行时。能 pip 解决的事，不引入构建链。

站点的版本号哪来的？

前端直接请求 api.github.com/repos/LK-BLOG/MollyPaw/releases（带 CORS，每 IP 每小时 60 次），版本号、发布时间、资产大小、历史记录全部实时取。请求失败时回落到同目录的静态快照 releases.json。

国内拉不到 Release 怎么办？

页面里的镜像列表会并行探一次 HEAD 到各加速节点的真实资产地址，把通的排前面。加速节点列表在 assets/js/main.js 里，挂了自己加。
